# Vision Website — releases

Release builds of the **Vision Website** WordPress plugin for The Travel
Network Group member sites. This repo holds nothing but releases: the
plugin's source is in a private repo.

Installed sites check here for updates automatically and offer them in
**Dashboard → Updates**. Each release has one asset, `vision-website.zip`,
which is the only file sites install.

To install by hand, download `vision-website.zip` from the
[latest release](../../releases/latest) and upload it in
**Plugins → Add New → Upload Plugin**.

Releases are published by the source repo's `bin/release.sh`. Don't commit
anything else here, and don't attach other files to a release.
